# 플랫폼개발팀 용어집

| 용어 | 뜻 |
|------|----|
| access token | API 요청마다 붙이는 짧은 수명(15분)의 인증 토큰 |
| refresh token | access token 을 다시 받을 때만 쓰는 긴 수명(14일)의 토큰. DB에 저장한다 |
| 재발급 | refresh token 으로 새 access token 을 받는 일. `/auth/refresh` |
| 마이그레이션 | DB 스키마 변경 파일. `migrations/` 에 번호 순으로 쌓는다 |
| 핫픽스 | 정기 배포를 기다리지 않고 바로 내보내는 긴급 수정 |
| 배포 동결 | 정해진 기간 동안 운영 배포를 멈추는 것 |
