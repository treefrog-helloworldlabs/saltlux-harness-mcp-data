# 플랫폼개발팀 보안 규정

시행 2026-09-01 · 관리 플랫폼개발팀

## 1. 비밀번호
- 비밀번호는 bcrypt 해시(cost 10 이상)로만 저장한다.
- 평문 비밀번호를 로그·오류 메시지·응답 본문에 남기지 않는다.

## 2. 토큰
- access token 수명은 15분, refresh token 수명은 14일이다.
- refresh token 은 DB에 저장하고, 재발급에 실패하면 즉시 폐기한다.
- 서명 키(JWT_ACCESS_SECRET, JWT_REFRESH_SECRET)는 환경변수로만 읽는다.

## 3. 로그
- 요청 로그에는 메서드와 경로만 남긴다. 요청 본문(req.body)은 기록하지 않는다.
- 로그인 실패 응답은 이메일 오류와 비밀번호 오류를 구분하지 않는다(동일 401).

## 4. 저장소
- `.env` 파일은 커밋하지 않는다. 필요한 키 목록은 `.env.example` 에 둔다.
- 이미 적용된 `migrations/*.sql` 은 고치지 않는다. 스키마 변경은 새 번호 파일로 추가한다.
